# The real film's code

The code of a 5:16 film on the Age of Aquarius, copied as it rendered. Read it for technique, and grep it by name: `references/picture.md` has a map of what is where.

It does not run on its own. It needs a table of planet positions (`data.js`), its timing files and its `lib.js`, which are not here (`lib.js` is the same as in the template). `score.py` is the older single-file form of the template's `audio/score.py` plus `audio/mixlib.py`.

The character, the story and the designs belong to that film. Learn from them and make your own.
